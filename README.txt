ВК РЕНОВАЦИЯ — ОБЛЕГЧЁННАЯ ВЕРСИЯ

Все видео и фотографии загружаются по HTTPS с исходных серверов.
Поэтому архив маленький, а качество медиа не снижено.

Запуск:
1. npm install
2. npm start
3. Открыть http://localhost:3000

Для обычного хостинга загрузите содержимое папки public.
Точка входа с экраном загрузки: preloader.html.
