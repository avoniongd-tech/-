ВК РЕНОВАЦИЯ — ГОТОВЫЙ САЙТ

Быстрый запуск:
1. Установите Node.js 18 или новее.
2. Откройте терминал в папке vk_renovation.
3. Выполните: npm install
4. Выполните: npm start
5. Откройте: http://localhost:3000

Для обычного хостинга загрузите содержимое папки public в корневую папку сайта.
Главная точка входа с видео-загрузкой: preloader.html.
Если хостинг открывает index.html автоматически, настройте preloader.html как DirectoryIndex
или переименуйте preloader.html в index.html, а текущий index.html — в main.html,
после чего в preloader.html замените переход index.html на main.html.

Видео:
- assets/video/loading-intro.mp4 — экран загрузки, Full HD 1920×1080.
- assets/video/hero-background.mp4 — видеофон главной, 720×1280.
Оба файла сохранены локально без повторного сжатия.
