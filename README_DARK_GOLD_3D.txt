VK RENOVATION — DARK GOLD ARCHITECTURE

Премиальный dark-gold сайт на базе старой сборки с загрузочным экраном.

Главная после загрузки: /main
AI Studio: /ai/
Admin: /admin/

Особенности:
- GPU WebGL architectural sculpture with drag-to-explore;
- dark-gold visual system;
- enhanced video 2560px master files with color correction and Lanczos upscale;
- editorial projects;
- scroll reveal, hover motion and responsive layout;
- reduced-motion fallback;
- working server, forms, AI Studio and admin.

Важно: 8K native-видео из исходников невозможно восстановить. Enhanced-видео увеличены до 1440p/2560p для production-версии. Неполные 8K masters удалены, чтобы не включать повреждённые файлы.

Запуск:
npm install --production --no-save
npm start
